## 🔥 1. Pagination + Search + Sort Table (MOST COMMON)

### 🧠 Problem

- Build a table that:
- Fetches paginated data from API
- Supports search
- Supports column sorting
- Shows loading & error states

## 🎯 Interviewer tests

- State design
- Controlled inputs
- Avoiding re-fetch loops
- Pagination logic

## ⚠ Common mistakes

- API call on every keystroke (no debounce)
- Mutating data while sorting
- Mixing UI & API logic
